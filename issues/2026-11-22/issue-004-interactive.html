Why Independent Critics, Lean 4 Tool Gates, and Edit Memory Scale Safe RSI

Four November studies and today's VEIO snapshot anchor Issue 004. Independent critics, Lean 4 tool proofs, eval-free diff merges, and edit memory cut drift and cost.

Before · Old Ceiling

Now · Signal-Locked Loop
S2N adds Lean 4 tool proofs and parallel critics. Eval-free merges and edit memory keep fixes intact.

01Independent Critics Beat Heavy Completion Gates on Cost

Teams wonder where to place checks inside an agent loop. Testing 17 designs across 7 models gave a clear answer. Initial rules and mid-turn reminders delivered small, uneven gains. Heavy completion gates raised accuracy but spiked token spend.

Independent critic review gave the best gain per dollar. Accuracy rose 5.9 to 9.5 points on Terminal-Bench at 1.13x to 1.25x cost. On SWE-bench Verified, scores rose 3.9 to 6.6 points at 1.00x to 1.04x cost. Four parallel critics hit 65.8% at 19% lower cost than four sequential rounds.

02LeanGuard Stops Forbidden Tool Calls in Milliseconds

Prompt-level warnings break when tool outputs hide injected orders. LeanGuard checks every proposed tool call against Lean 4 temporal rules first. Its fail-closed monitor inspects trace history before any write runs. Across 5 Qwen models, LeanGuard ran 0 forbidden calls versus 33 plus unguarded.

Blocking bad calls alone can trap workers in blind retries. LeanGuard returns exact broken rules and offers offline proof-guided repair. On DTap, direct prompt-injection success dropped from 57.9% to 5.9%. Offline repair fixed 88 of 252 argument denials in 2 ms median.

Key Takeaway
“Keep deterministic tool gates at the boundary, move cheap critics to review, and carry edit rationales across every model swap.”
