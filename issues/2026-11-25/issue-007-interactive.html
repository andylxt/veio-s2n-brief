01Frontier Leads Plus Local SLMs Cut Coding Spend by 67%

Frontier agents burn tokens re-reading files and logs. Waterloo researchers built Delegent inside Claude Code to fix this. GPT-6.1-Sol stays the lead and keeps all core code edits. Local 27B or 2B subagents run code search and test sweeps.

Delegation cut spend with zero drop in solve counts. On DeepSWE, frontier cost fell 67% from $2.110 to $0.704. Across 694 search questions, cost dropped 59% at 663 solves. Even a 2B laptop model cut DeepSWE spend by 66%.

02Model Choice Drives 75.5% of Agent Safety Variance

Teams often ask if harness tricks beat stronger models. ShellBench graded 100 messy workspace tasks across 53,100 agent rollouts. It tested 12 models across 5 harnesses and 3 effort levels. Top models landed within 1.1 points from 61.4% to 62.5%.

Safety and cost split the field wide open. GPT-6.1 Sol hit 61.4% at one-sixth of GPT-6 Astra cost. Model choice explained 75.5% of safety failure swings vs 4.7% for harnesses. GPT-6.1 Sol failed 9.7% of safety rules vs 20.6% on Gemini 4 Carbon.

AEGIS Catches Hijacked Multi-Agent Leaks in 500 ms via eBPF

Prompt traps can hijack trusted agents behind encrypted LLM links. Texas Tech and NVIDIA researchers built AEGIS to close that gap. It turns each task brief into strict syscall rules. Kernel eBPF probes watch reads, forks, and sockets every second.

Real-path tests caught every attack on the first check cycle. AEGIS caught 4/4 attack types across 3/3 runs in 500 ms. Verifier CPU load stayed under 0.055% on a 256-core host. Six clean workflows covering 42 steps hit zero false flags.

RSI Infrastructure · Lifecycle Flash

Mayfly Cuts 256-Session RSI Runtime 55% With Session-End Hooks

Parallel RSI evaluations spike GPU memory when candidates run together. National University of Singapore and HUST researchers built Mayfly. It reads flash KV blocks in place only during HBM overflow. When the orchestrator marks a job done, dead KV clears fast.

Lifecycle hooks beat static parking across heavy RSI workloads. At 128 sessions, runtime fell 34% from 482 to 316 minutes. At 256 sessions, runtime fell 55% from 919 to 417 minutes. Preemptions dropped from 735 to zero across every generation.
